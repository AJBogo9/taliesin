# notes/

Internal working notes: roadmap, backlog, audits, and research. These are
notes-to-self, **not** shipped with the tool and not part of the rendered manual
(that lives in `docs/`). The public-facing files (`README.md`, `LICENSE`,
`THIRD_PARTY.md`) and the AI-assistant instructions (`CLAUDE.md`) stay at the repo
root.

| File | What it is |
|---|---|
| `CUT-PROGRESS.md` | **START HERE while the scope reduction is running.** The durable state for the 2026-08-08 cut: waves landed, wave next, the rules, the standing "lean towards cutting" directive. |
| `2026-08-08-scope-ruling.md` | The ruling behind the cut: verdicts on 18 bundles, the evidence, and the four corrections the final skeptic forced. |
| `2026-08-08-cut-playbook.md` | The mechanics: 182 file-level removal steps, grouped by wave. Reference, not reading material. |
| `backlog.md` | The **canonical** to-do list. Pruned 2026-08-07 to the release critical path only: seven items, and nothing new is filed there unless it blocks the release. |
| `DO-NOT-REBUILD.md` | The anti-rot register: shipped, declined, refuted, and the known non-defects. **Not a task list.** Read before re-filing anything that "looks missing". |
| `LESSONS.md` | Method: how to probe, measure and pin without getting a false result. Read before writing a probe or a test. |
| `ROADMAP.md` | The **active** roadmap: the corpus-plus-roadmap initiative. |
| `native-rewrite.md` | The completed predecessor initiative (native engine, dropped the legacy compat layer). |
| `AUDITS.md` | Consolidated historical audit reports. |
| `FEATURE-IDEAS.md` | A research-backed pool of candidate features that feeds the backlog. |
