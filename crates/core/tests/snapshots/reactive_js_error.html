{js} cell error state

A {js} cell that throws at runtime surfaces the .tali-js-error box. The box is themed for light and dark (the dark override lives in dark.css), so this doc pins that runtime-error state as a target for browser verification. The corpus render only emits the cell (JS runs in the browser, not at build time), so this doc renders without warnings like any other.

Prose after the failing cell still renders normally, confirming one cell’s error does not wedge the rest of the page.
