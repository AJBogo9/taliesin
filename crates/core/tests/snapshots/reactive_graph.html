Reactive cells: a dependency graph

{js} cells form a dependency graph through //| viewof (a named input control), //| name (a value a cell publishes), and //| input (what a cell consumes). Moving a slider re-runs only the cells downstream of it, in dependency order, including cells that depend on it transitively through a derived value.
